Executive summary

Airin adalah platform agen AI multi-tenant untuk tim bisnis. Pemilik usaha punya “tim” agen dengan peran jelas (Ops, Finance, Analyst, HR, Sales, CS, Social). Agen bekerja bersama lewat grup chat atau lewat orkestrator (Jovan) yang mendelegasikan tugas ke spesialis.

  • Produksi berjalan di useairin.id. Uji grup Business (Toni, Dimas, Ardi, Alya) menghasilkan dashboard income vs expense + forecast dari Google Sheet.
  • Simple mode untuk owner non-teknis sudah jadi: sidebar tim + peran, Groups, Marketplace, lanjut chat terakhir.
  • Landing publik + waitlist aktif. Belum ada signup / pembayaran (sengaja).
  • Gap terbesar: business profile (P0-12) belum dibangun, sheet besar tidak muat di Data View, belum ada release tag sejak v0.4.74.

BRD — Model produk

Mental model

  1. Organization — batas isolasi data (members, profiles, sessions, tools, memory).
  2. Profile (agent) — identitas (soul), model, tools, skills, knowledge base.
  3. Akses tools/skills/MCP/plugin — eksplisit per profil.
  4. Channel — semua channel memakai profil yang sama.

Cara agen bekerja sama

  • Agent group — owner bicara ke 2–12 agen dalam satu chat (@handle, @all).
  • A2A send_to_bot — orkestrator mengirim tugas ke spesialis, menunggu jawaban, lalu merangkum. Max 3 hop.

Mode UI

  • Simple — owner bisnis (default install baru).
  • Advanced — admin / operator.

Arsitektur (ringkas)

Clients (web, CLI, desktop) + channel workers → HTTP/SSE dengan X-Org-Id → server Hono (rate limit → auth → org → routes) → AgentService (tools, MCP, plugins, skills) → SQLite + file soul/memory.

Satu container Docker: API + web + workers. Data di /airin/data, dashboard port 4310. Batas lean: ≤512 MB RSS untuk core.

Product roadmap

Urutan dari sprint backlog dan gap BRD. Tanpa tanggal: estimasi ada di docs/sprint-backlog*.md.

Now — selesaikan P0

  • P0-12 Business profile: nama, alamat, layanan, harga, jam, WA, Maps, tone — masuk ke prompt semua agen

  • P0-4: hubungkan dan uji API cuaca

  • Jejak delegasi A2A terlihat di UI
  • Lanjut chat lintas device: simpan session terakhir di server
  • P1-4 Production hardening (secrets, backup drill, RSS ≤512 MB)
  • P1-6 Image generation untuk agen Social
  • P1-8 Finance: sync sheet berkala + template skenario

Later — komersial & skala

  • P1-1 Pembayaran (Stripe / regional)
  • P1-2 Dashboard super admin
  • P1-5 Posting sosial + carousel
  • P1-7 Visibility: GBP / Maps first-class
  • P1-9 Router onboarding vertical (≥3 vertical)
  • Gap: SSO/SAML, API key mesin, audit log untuk customer, plugin sandbox, OCR
