# 00. Peta halaman dan klik di mana

> Bab ini adalah peta hyperlink ke halaman dashboard. Pakai saat Anda tidak tahu menu mana yang harus dibuka. Semua tautan di bawah membuka halaman yang sama di tab ini (wajib login).

**Siapa yang bisa:** semua pengguna yang sudah login. Beberapa halaman hanya untuk admin organisasi atau platform admin.

## Screenshot cepat

### 1. Sidebar Simple — klik **Panduan** atau **Pengaturan**

![Sidebar Simple: Marketplace, Panduan, Pengaturan](/user-guide/sidebar-simple.png)

1. Di kiri bawah, klik **Panduan** untuk membuka [Panduan](/guide).
2. Klik **Pengaturan** untuk membuka [Preferences](/settings/preferences).
3. Klik **Marketplace** untuk membuka [Marketplace](/marketplace).
4. Di **Tim Anda**, klik **Airin** (subtitle **Bantu kelola platform**) untuk tanya cara setup — Airin menjawab dengan tautan yang bisa diklik dan bisa ikut mengatur lewat tools.

### 2. Hub Settings (mode Advanced)

![Hub Settings](/user-guide/settings-hub.png)

1. Mode **Advanced**: sidebar → **Settings** → [hub Settings](/settings).
2. Pilih kartu halaman (Organization, Providers, Tools, …).

### 3. Marketplace

![Marketplace](/user-guide/marketplace.png)

1. Buka [Marketplace](/marketplace).
2. Pilih paket agen, lalu install sesuai peran Anda.

## Tanya Airin (one-point)

**Kenapa:** Tidak perlu hafal semua menu.

**Cara pakai:**
1. Buka chat dengan **Airin** di [Tim Anda](/chat) (Simple) atau rail Advanced.
2. Tulis pertanyaan, contoh: “Di mana set API key?”, “Undang member”, “Pasang agen laundry”.
3. Airin membalas dengan tautan Markdown (klik langsung) dan/atau mengerjakan perubahan dengan tools-nya.
