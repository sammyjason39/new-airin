# send_to_bot

Send a task to **another agent in the same organization** and wait for its reply. The other agent answers with its own instructions, memory, and tools — for example a finance agent that reads your sheets.

Use [`sub_agent`](/tool-reference#sub_agent) for work the same profile should do. Use `send_to_bot` when a different specialist should answer.

An orchestrator such as Jovan calls `send_to_bot` once per teammate, then writes one answer for you and says which teammate supplied each fact.

| Parameter | Type | Required | Notes |
|-----------|------|----------|-------|
| `bot_name` | string | Yes | Name of the target agent. Case does not matter. A unique start of the name or a unique part of it also works |
| `message` | string | Yes | What the other agent should do. Include the sheet, period, or context it needs |
| `timeoutMs` | number | No | Default 300000 (5 min) |

**Returns:** `{ status, from, summary, output, error? }` where `from` is the agent that answered.

**Limits:**

- An agent cannot send to itself
- A chain of agents sending to agents stops after 3 steps
- If no agent matches the name, the error lists the agents in the organization

**Availability:** Added automatically to every chat turn. Not available in read-only chats or in turns that limit tools.

See also [Agent groups](/agent-groups) for several agents in one chat, and [Tool reference](/tool-reference) for the full tool list.
